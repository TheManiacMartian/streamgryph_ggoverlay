# streamgryph_ggoverlay
 The standard overlay for Gryphon Gaming streams. Uses StreamGryph to read data.

The guide to setup the overlay for StreamGryph is [here](https://github.com/TheManiacMartian/streamgryph/wiki/Setting-up-Overlay-in-OBS-(Gryphon-Gaming)).

## Font Installation
THE FONT FOR THE STREAM NEEDS TO BE INSTALLED FROM [HERE](https://www.dafont.com/moderniz.font).

After downloading it please install it to your computer by opening it and clicking on install font.

After it is installed restart OBS and set the font for all text scenes (if it didn't already set itself).
